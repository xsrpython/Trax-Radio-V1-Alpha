# 📱 Google Play Store Assets Guide

## **Required Assets for Trax Radio UK**

### **1. App Icon**
- **Size**: 512x512 pixels
- **Format**: PNG
- **Status**: ✅ Already created (`assets/traxicon.png`)
- **Usage**: App icon in Play Store and on device

### **2. Feature Graphic**
- **Size**: 1024x500 pixels
- **Format**: PNG or JPEG
- **Status**: ❌ Needs to be created
- **Usage**: Banner image in Play Store listing

### **3. Screenshots**
- **Phone Screenshots**: 2-8 screenshots
- **Size**: 16:9 ratio, minimum 320px height
- **Format**: PNG or JPEG
- **Status**: ❌ Needs to be created
- **Usage**: Show app interface and features

## **Screenshot Creation Process**

### **Method 1: Android Emulator**
1. **Start Android emulator**
2. **Install and run Trax Radio UK**
3. **Navigate to different screens**
4. **Take screenshots** (Ctrl+S in emulator)
5. **Edit and add text overlays**

### **Method 2: Physical Device**
1. **Install APK on Android device**
2. **Use device screenshot** (Power + Volume Down)
3. **Transfer to computer**
4. **Edit and add text overlays**

### **Method 3: Screenshot Tools**
1. **Use tools like Snagit, Greenshot, or built-in tools**
2. **Capture app screenshots**
3. **Add professional text overlays**
4. **Resize to required dimensions**

## **Text Overlay Guidelines**

### **Font Specifications**
- **Font**: Roboto or similar modern font
- **Size**: 24-32px for main text, 16-20px for subtext
- **Color**: White with black outline for visibility
- **Style**: Bold for main text, regular for subtext

### **Text Content Examples**
- "Live Radio Streaming"
- "Real-time DJ Information"
- "Beautiful Audio Visualization"
- "Background Audio Support"
- "Professional Interface"
- "No Ads, No Registration"

### **Text Placement**
- **Position**: Bottom of screenshot
- **Background**: Semi-transparent dark overlay
- **Padding**: 20px from edges
- **Alignment**: Center or left-aligned

## **Asset Optimization**

### **File Size Guidelines**
- **App Icon**: Under 1MB
- **Feature Graphic**: Under 1MB
- **Screenshots**: Under 1MB each
- **Total**: Under 8MB for all assets

### **Quality Settings**
- **Format**: PNG for icons, JPEG for screenshots
- **Compression**: High quality, minimal compression
- **Resolution**: Exact pixel dimensions required
- **Color Profile**: sRGB
