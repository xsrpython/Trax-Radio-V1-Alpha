## 📋 Installation Instructions

### For Beta Testers
1. Download the APK from the provided link
2. Enable "Install from Unknown Sources" in Android settings
3. Install the APK file
4. Launch Trax Radio UK app
5. Grant necessary permissions when prompted

### Permissions Required
- **Internet Access**: For live radio streaming
- **Audio Focus**: For proper audio playback management
- **Wake Lock**: To prevent audio interruption during calls
