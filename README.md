## 🏗️ **Technical Architecture**

### **Core Services**
- **Audio Service** - Just Audio plugin with background support
- **DJ Service** - Auto-fetches schedule from official website
- **BPM Service** - Beat detection and visualization
- **Metadata Service** - Song information display

### **Key Dependencies**
- `just_audio` - Audio streaming
- `timezone` - Schedule timezone handling
- `http` - API communication
- `path_provider` - File system access
