# 🆓 **Firebase App Distribution - FREE Google Option**

## **What is Firebase App Distribution?**
- **Cost**: FREE
- **Provider**: Google
- **Benefits**: Professional app distribution
- **Features**: Beta testing, crash reporting, analytics

---

## **Step 1: Set Up Firebase Project (FREE)**

### **✅ Create Firebase Project:**
1. **Go to**: https://console.firebase.google.com/
2. **Click** "Create a project"
3. **Project name**: "Trax Radio UK"
4. **Enable Google Analytics**: Yes
5. **Click** "Create project"

### **✅ Add Android App:**
1. **Click** "Add app" → Android
2. **Package name**: `com.example.trax_radio`
3. **App nickname**: "Trax Radio UK"
4. **Debug signing certificate**: Optional
5. **Click** "Register app"

---

## **Step 2: Configure Firebase in Flutter**

### **✅ Add Firebase Dependencies:**
```yaml
# pubspec.yaml
dependencies:
  firebase_core: ^2.24.2
  firebase_analytics: ^10.7.4
  firebase_crashlytics: ^3.4.8
  firebase_app_check: ^0.2.1+8
```

### **✅ Install Dependencies:**
```bash
flutter pub get
```

### **✅ Download google-services.json:**
1. **Download** from Firebase Console
2. **Place** in `android/app/google-services.json`

---

## **Step 3: Build Release APK**

### **✅ Build APK:**
```bash
flutter build apk --release
```

### **✅ APK Location:**
```
trax_radio/build/app/outputs/flutter-apk/app-release.apk
```

---

## **Step 4: Firebase App Distribution**

### **✅ Upload to Firebase:**
1. **Go to** Firebase Console
2. **Click** "App Distribution"
3. **Click** "Upload APK"
4. **Select** your APK file
5. **Add release notes**: "Trax Radio UK v1.0 - Live Dance Music"

### **✅ Create Distribution Group:**
1. **Click** "Create group"
2. **Group name**: "Trax Radio Testers"
3. **Add testers** by email
4. **Set permissions** for testing
